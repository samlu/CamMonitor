# CamMonitor 監控攝影機

> **語言版本：** [English](README.md) | [繁體中文](README_TW.md) | [日本語](README_JA.md)  
> **開發心聲：** [為什麼要做這個專案？一位四十多年老工程師的 AI 實踐心聲](WhyCreateThisProject_TW.md)

![CamMonitor 宣傳橫幅](cammonitor_promo_tw.jpg)

CamMonitor 能將您閒置的舊 Android 手機化身為居家安全監控攝影機。透過端對端加密（P2P）直接連線，支援 Wi-Fi 區域網路與行動數據外網，無需註冊帳號、無雲端訂閱費用，更不會有任何第三方伺服器儲存您的視訊畫面。

---

## 主要特色

- **零帳號設定：** 無需註冊、不需密碼，透過單次動態加密 QR Code 即可迅速完成配對。
- **嚴密端對端安全性：** 採用硬體級 ECDSA 金鑰驗證與 AES-256-GCM 點對點加密，只有經過授權配對的裝置才能連線觀看。
- **雙重裝置角色與網頁觀看端：**
  - **鏡頭模式（Camera Mode）：** 安裝於固定架設的 Android 手機（擷取 720p 高畫質影像與即時音訊）。
  - **觀看模式（Android App / 網頁瀏覽器 / iPhone）：** 除了使用 Android 隨身手機監看外，亦支援 **iPhone/iPad Safari（可加入主畫面 PWA）**、**電腦瀏覽器（Windows / macOS / Linux）** 或 **Android 瀏覽器**，透過靜態託管的 [**CamMonitor 網頁觀看端**](https://samlu.github.io/CamMonitor/viewer/) 直接加密連線觀看，免安裝 App 亦無需註冊雲端帳號。
- **多裝置支援：**
  - 1 台鏡頭最多可配對 **8 台觀看端**裝置，並最多同時串流分享給 **2 台觀看端**。
  - 1 台觀看端最多可配對管理 **8 台不同鏡頭**（例如客廳、大門、嬰兒房）。
- **智慧省電與螢幕保護：**
  - **全黑螢幕省電與觸控鎖定（防烙印）：** 靜置 60 秒或輕觸「關閉螢幕」按鈕後，螢幕自動轉為全黑以防止 OLED 烙印並節省電力；鎖定時釋放常亮鎖定，讓螢幕硬體完全休眠並使系統進入深度睡眠。鎖定觸控防止誤觸，滑動螢幕即可解鎖。
  - **智慧待命與動態 Wi-Fi：** 若超過 15 秒沒有任何觀看端連線，鏡頭會自動暫停感光元件運作並釋放高效能 Wi-Fi 鎖定以大幅降低耗電，待觀看端再次連線時自動喚醒。
  - **保護硬體壽命與防發熱機制：** 刻意不內建全時錄影與即時物件偵測，避免長時間開啟相機造成機身發燙、電池膨脹老化與相機感光元件壽命銳減。（若使用者有特定需求，可透過 AI 工具自行擴充加入）。
- **觀看端遠端控制功能：**
  - **三段夜間模式切換：** 可切換 `自動`（由環境光感測器偵測自動啟動）、`夜間`（強制啟動低光源增強）、`正常`（標準影像擷取）。
  - **遠端手電筒：** 遠端開啟或關閉鏡頭端手機的手電筒照明。
  - **雙向即時對講（PTT）：** 按住「按住對講」按鈕即可向鏡頭端發話擴音，放開即停止發話。
  - **畫面旋轉與比例調整：** 支援 90° 逐次旋轉（0° → 90° → 180° → 270°）以適應各種架設角度；支援「配合螢幕」（不裁切）與「填滿螢幕」切換（亦可輕觸兩下視訊畫面切換）。
  - **即時電量監控：** 同時顯示鏡頭端與觀看端的剩餘電量百分比與充電狀態。
- **自動新版發布偵測與系統通知：** 透過 Android WorkManager 定期（每 24 小時）自動查詢 GitHub Releases 最新版本，無需依賴 Google Play 服務。當有新版本發布且 App 未開啟或處於背景時，自動發送系統狀態列通知；App 內於首頁與「關於」畫面提供便利的更新資訊卡。
- **本機診斷記錄：** 內建滾動式系統記錄檢視器，支援一鍵分享匯出，找出連線問題與排除狀況更輕鬆。
- **多語言介面：** 支援繁體中文（台灣）、簡體中文、英文與日文，可隨時於設定切換。

## 系統需求

- **作業系統：** Android 9.0（Pie / API 28）或以上版本。
- **系統權限：** 相機、麥克風、通知權限（Android 13+）。
- **網路環境：** 兩支手機均需連線至網際網路（Wi-Fi 或行動數據）。支援同區域網路（LAN）與跨網外網連線（WAN）。

## 安裝方式

CamMonitor 以獨立 APK 形式於 GitHub Releases 發布，無需 Google Play 帳號亦無任何第三方雲端綁定。

1. **下載 APK 安裝檔：**
   - 在您的鏡頭手機與觀看手機上，前往 [**GitHub Releases**](https://github.com/samlu/CamMonitor/releases/latest)。
   - 在 **Assets** 區塊下載最新版本的 `Camonitor-vX.Y.Z.apk` 檔案。
2. **於 Android 系統安裝：**
   - 從瀏覽器下載清單或檔案管理員中點擊開啟下載的 `.apk` 檔案。
   - 若系統跳出「為了保護您的安全，手機目前不允許安裝來源不明的應用程式」提示：
     1. 點選對話框中的 **「設定」**。
     2. 開啟 **「允許來自此來源的應用程式」**。
     3. 返回安裝畫面並點選 **「安裝」**（或 **「更新」**）。
3. **首次啟動權限授予：**
   - 首次開啟時，請授予 **相機** 與 **麥克風** 權限（視訊串流與雙向語音對講必要權限）。
   - Android 13+ 裝置請允許 **通知** 權限（背景常駐串流服務與新版本發布通知必要權限）。

*（開發者亦可透過 ADB 指令直接安裝：`adb install -r Camonitor-vX.Y.Z.apk`）*

## 使用教學

### 1. 首次配對（只需設定一次）

開始使用前，請先將兩台裝置進行安全配對：

1. **在鏡頭手機上：**
   - 開啟 CamMonitor。
   - 點選 **「啟動鏡頭模式」**（若尚未配對過，可點選「配對觀看端」）。
   - 螢幕上將顯示專屬配對 QR Code。
2. **在觀看裝置上：**
   - **Android 觀看端 App：** 開啟 CamMonitor，點選 **「啟動觀看模式」**（或「配對鏡頭」），掃描鏡頭手機上的 QR Code。
   - **iPhone / iPad（免安裝網頁觀看端）：** 直接開啟 iPhone 原生「相機」掃描鏡頭手機上的 QR Code，點擊 Safari 橫幅開啟 `https://samlu.github.io/CamMonitor/viewer/` 即可自動完成配對。*（提示：在 iPhone 上建議點選 **分享 → 加入主畫面** 後，於主畫面 App 內配對一次以永久保留已配對鏡頭。）*
   - **筆記型電腦 / 桌機瀏覽器：** 在鏡頭手機 QR 碼下方點選 **「分享連結」** 或 **「複製連結」** 傳送至電腦並點擊開啟，即可自動配對；亦可開啟網頁觀看端使用網路攝影機掃碼或貼上連結。
3. 確認完成後，雙方即永久記住配對，後續開啟無需重新配對。*（單次配對金鑰僅存在於網址 `#pair=` 片段中，瀏覽器不會將其傳送至 GitHub Pages 伺服器。）*
   - *開發者自行部署：* 請參閱 [WEB_VIEWER_DEPLOY.md](WEB_VIEWER_DEPLOY.md) 了解如何將網頁觀看端部署至您自己的 GitHub Pages。

---

### 2. 使用鏡頭模式（放置於監控位置的手機）

1. 開啟 CamMonitor，點選 **「啟動鏡頭」**（或點選 **「黑畫面啟動」** 直接以 OLED 全黑防觸控模式啟動串流，避免夜間照亮嬰兒房或臥室；第一次使用會先以簡短對話框說明畫面將全黑以及如何滑動解鎖）。若電量 30% 以下且未充電，按鈕上方會以琥珀色提示先接上充電器。若尚未配對任何觀看端，會先進入配對 QR 碼畫面，配對完成後仍依你選擇的模式啟動（選「黑畫面啟動」就會維持黑畫面）。
2. 將手機固定於欲監控的視角位置。
3. 離開前可檢視主畫面頂部 **硬體狀態檢測列**，確認充電狀態（`⚡ 充電中`）與網路連線正常。此列會在插拔電源或網路變化時即時更新；若網路已連上但無法上網（例如需登入的公共 Wi-Fi）會以琥珀色顯示「無法連上網際網路」，使用有線網路時則顯示「乙太網路已連線」。
4. **介面說明與省電機制：**
   - **頂部 HUD 狀態列：** 顯示串流解析度與影格率（`720p 15fps`）、目前同時連線觀看人數（直向顯示 `0/2`，橫向顯示 `0/2 觀看中`）、已配對觀看端數量（直向顯示 `3/8`，橫向顯示 `3/8 已配對`）、夜間與手電筒狀態。
   - **螢幕運作與關閉螢幕省電：** 於預覽且解鎖狀態下維持螢幕常亮；靜置 60 秒無操作（或輕觸左下角 **「關閉螢幕」** 按鈕），進入全黑模式並釋放常亮鎖定，讓螢幕休眠並使系統進入深度睡眠以達到最佳省電效果。**滑動螢幕**即可解鎖恢復預覽，鎖定期間返回鍵無效。
   - **自動待命與動態 Wi-Fi：** 若連續 15 秒無人連線觀看，系統自動進入待命省電狀態並釋放高效能 Wi-Fi 鎖定，當觀看端連入時會自動恢復。
5. **退出模式：** 輕觸右下角 **「退出鏡頭」**（或按手機返回鍵）即可停止串流。

---

### 3. 使用觀看模式（日常隨身攜帶的手機）

1. 開啟 CamMonitor，直接點選監看鏡頭卡片的任何位置（或其 **「連線 ▶」** 按鈕），零彈窗延遲立即進入即時視訊串流。長按卡片可解除該鏡頭配對（會先顯示確認對話框）。
2. 如需新增監看鏡頭，輕觸 **「+ 配對鏡頭」**（最多支援 8 台鏡頭）。若此手機只用來觀看（已配對鏡頭、未配對任何觀看端），主畫面會優先顯示鏡頭清單，並將「鏡頭端」區塊收合成精簡的一列。
3. **監控與操作面板：**
   - **頂部控制列：**
     - 顯示鏡頭自訂名稱與連線狀態標籤。
     - 雙機電量指示：顯示鏡頭電量（例如 `鏡頭 85%⚡`）與本機電量（`觀看端 90%`）。
     - **夜間模式切換鈕：** 輕觸可在「自動」、「夜間」、「正常」之間循環切換。
     - **手電筒切換鈕：** 輕觸可遠端開關鏡頭端手機的手電筒。
   - **底部控制列：**
     - **旋轉視角（90°）：** 每次輕觸順時針旋轉畫面 90 度，解決倒置或側向架設問題。
     - **畫面比例：** 在「配合螢幕」（不裁切）與「填滿螢幕」間切換（亦可輕觸兩下視訊畫面切換）。
     - **語音對講（PTT）：** 長按 **「按住對講」** 即可對著鏡頭說話，放開按鈕即停止傳送。
     - **鏡頭靜音：** 輕觸喇叭圖示可開啟或關閉鏡頭端傳來的環境聲音。
3. **退出模式：** 輕觸左上角返回箭頭或使用系統手勢返回主畫面。

## 設計考量：保護硬體壽命與防發熱機制

為了保護長時間作為鏡頭的手機，避免電池老化膨脹、機身持續高溫以及感光元件壽命大幅縮短，CamMonitor 特別設計為**依需求即時監看（On-Demand）**架構，而非 24 小時連續錄影系統：

- **未內建全時錄影功能：** 長時間不間斷開啟鏡頭與視訊編碼器會造成機身劇烈發熱，嚴重損耗相機感光元件與鋰電池壽命。
- **未內建物件／動態偵測：** 即時電腦視覺演算法（如物件偵測）需強迫鏡頭感光元件與處理器全時處於高負載運作狀態。
- **智慧待命休眠：** 超過 15 秒無人連線觀看時，鏡頭端會完全關閉相機硬體進入低耗電待命狀態，直到觀看端連入時自動喚醒。
- **自行擴充功能：** 若您的使用情境確實需要連續錄影或物件偵測，本專案為開源架構，您可以利用 AI 程式碼輔助工具在此專案的現有基礎上自行擴充加入（例如整合 CameraX `VideoCapture` 或 MLKit 物件偵測模組）。

## 隱私與安全承諾

- **無雲端視訊轉發：** 影音視訊透過 WebRTC 直接在您的手機間點對點傳輸。
- **端對端高規格加密：** 傳輸全程使用 DTLS-SRTP 與 AES-GCM 加密防護。
- **零隱私外洩風險：** 無帳號密碼外洩風險，亦無任何視訊備份留存於任何公有雲端。
